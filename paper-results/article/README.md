# Current article outputs

Use the full/, qualified/ and trimmed/ subfolders generated by make_article_outputs.R.
Each contains article_figures.pdf, figures/, tables/, data/ and editable plots.rds.
Qualified requires stable AR and invertible MA; convergence is only a diagnostic.
Trimmed starts from the full usable sample, removing 1% of losses from each tail.
Any older figures or tables directly in this parent folder belong to the previous export.
